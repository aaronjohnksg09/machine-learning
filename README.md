# 🏠 Machine Learning Basics: House Price Analysis

Welcome to my Machine Learning learning repository! 👋

This project documents my journey of learning the fundamentals of data analysis and machine learning using the **House Prices dataset from Kaggle**.

## 📌 Project Focus

Before building machine learning models, it is important to understand the data. In this project, I practised working with house-price data to develop essential data-analysis skills.

## 🔍 What I Have Learned

Using Python and Pandas, I explored how to:

- Inspect datasets to understand rows, columns, data types, and missing values.
- Sort data to find houses with the highest, lowest, or specific prices.
- Filter records based on conditions such as price, location, or house features.
- Group data by categories to compare property values.
- Aggregate data using calculations such as mean, sum, minimum, maximum, and count.
- Generate descriptive statistics to understand trends and data distribution.
- Explore relationships between house features and sale prices.

## 🛠️ Tools Used

- Python
- Pandas
- Jupyter Notebook
- Kaggle House Prices Dataset

## 🎯 Goal

The goal of this repository is to build a strong foundation in:

- Data cleaning
- Exploratory Data Analysis (EDA)
- Data preparation
- Machine Learning fundamentals

As I continue learning, this repository will grow to include machine learning models that can predict house prices based on property features.

## 📊 Dataset

The dataset used in this project is the **House Prices: Advanced Regression Techniques** dataset available on Kaggle.

🔗 [View the dataset on Kaggle](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)
